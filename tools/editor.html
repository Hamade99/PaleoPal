PALEOPAL ART

Every small sprite in the game. The left button uses the tool, the right button always erases, and Alt-click picks up a colour. The palette is per sprite — change a colour and every pixel using it changes with it. Keys: the letter on each tool, 1–0 and [ ] for colours, + − zoom, # grid, Ctrl+Z undo, Ctrl+Y redo. Select (S) boxes a region: drag inside to move it, Alt-drag for a copy, arrows nudge, Ctrl+C/X/V copy, cut and paste. Open beside puts a second sprite next to this one at the same zoom; the list picks for whichever pane is outlined.
